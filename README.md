# Boussole 2026

Suivi des objectifs 2026 : quatre pôles (Carrière & mobilité, Sérénité & esprit, Famille & cœur, Liberté financière), avec actions, indicateurs, statuts et taux de réalisation. Exports PDF, Excel et Word.

Dépôt privé. Il contient uniquement le code (`index.html`), aucune donnée personnelle.

## Origine

Code récupéré de l'artefact claude.ai « Boussole 2026 — Suivi des objectifs ».

## Limites hors claude.ai

- Les objectifs sont stockés dans la base de l'artefact (`boussole/data`), pas dans ce dépôt.
- Hors de claude.ai, la base partagée n'existe pas : la page retombe sur le stockage local du navigateur.
- Les téléchargements PDF, Excel et Word passent par une fonction de claude.ai : ils ne fonctionnent pas hors de claude.ai en l'état.
